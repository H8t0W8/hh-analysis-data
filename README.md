# Проект 1. Анализ вакансий из HeadHunter

## О проекте
В данном проекте проводится разведывательный анализ данных (EDA), преобразование признаков и очистка базы резюме соискателей с сайта hh.ru.

### Основные этапы работы:
1. **Базовый анализ структуры данных** — исследование типов признаков и первичных статистик.
2. **Преобразование данных** — выделение признаков образования, опыта работы, пола, возраста, города, типов занятости и графиков работы (One Hot Encoding), а также перевод заработной платы в рубли по курсу на дату обновления резюме.
3. **Разведывательный анализ (EDA)** — поиск зависимостей и аномалий с помощью визуализации (`matplotlib`, `seaborn`).
4. **Очистка данных** — удаление дубликатов, обработка пропусков и ликвидация выбросов.

## Файлы и данные
